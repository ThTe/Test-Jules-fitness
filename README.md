# Mobility Check & Progress App

This is a Flutter application designed to help users assess their joint and muscle mobility through a series of guided tests.

## Features
- Guided mobility tests with detailed criteria.
- Personalized diagnosis based on test results.
- A library of recommended exercises to address weaknesses.
- Progress tracking over time.

## Project Status
This project is currently under development. The core UI and logic have been implemented.
